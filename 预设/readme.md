## 0.osc
* 仅仅修改了默认osc的一些配置

## 0.thumbfastosc
* 仅仅修改了osc，基于默认osc，添加了进度条显示缩略图的功能

## 1.移动端
* 尽可能降低硬件需求，适合移动端等注重续航，降低噪音的情景，最低要求为2代赛扬双核双线程CPU，任意支持dx11显卡

## 2.平衡
* 平衡画质和硬件性能需求，适合老旧台式PC的情景，质量尚可，最低可流畅播放配置未知，任意常见四核CPU，750ti显卡即可

## 3.高质量PC[uosc dyn_menu lualite]
* 屏控用uosc，菜单用dyn_menu，减少其他lua数量。默认在PC上的配置

## 4.高质量HTPC[uosc lualite]
* 屏控用uosc，菜单用uosc，减少其他lua数量。默认在HTPC上的配置，必须有支持源码直通的全套声音设备

## _fruit[废弃]
* 上一个基于fruit osc，在PC上的默认配置，随着上游作者也不断偏向使用uosc，现在已经废弃！仅作保留
